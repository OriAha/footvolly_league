# חות'ים · ליגה שנייה ⚽

אפליקציית ווב (PWA) לקבוצת **חות'ים** בליגת החורף של אוקטופוס פוצ'יוולי 2026.

- **לוח המשחקים שלנו**: כל המשחקים לפי מחזור ותאריך, עם השעה, המגרש והיריבה. המשחק הבא מודגש.
- **לחיצה על יריבה**: השחקנים שלה, המאזן שלה (ניצחונות והפסדים), חמשת המשחקים האחרונים שלה, ורשימת התוצאות הקודמות שלה. כל תוצאה מסומנת בירוק לניצחון ובאדום להפסד, עם שם הקבוצה שמולה שיחקה.
- **המשחקים שלנו מולם**: התוצאה של המפגש בינינו, אם כבר שיחקנו.
- הנתונים נטענים בזמן אמת מ-[אתר הליגה](https://octopus-league-hub.base44.app/), ומתרעננים אוטומטית כל 2 דקות.
- אפשר להתקין על מסך הבית: בטלפון בוחרים "הוספה למסך הבית" / "Add to Home Screen". האפליקציה נפתחת גם בלי רשת, עם הנתונים האחרונים שנשמרו.

## טכני

אתר סטטי בלי שלב build: `index.html`, `app.js`, `styles.css`, ו-`sw.js` (service worker).
הנתונים נמשכים מה-API הציבורי של אפליקציית Base44 של הליגה, אותן הקריאות שהאתר עצמו מבצע לכל מבקר:
`Game`, `Team` ו-`League`. מהקבוצות נשמרים בדפדפן רק השם, השחקנים והצבע.

הרצה מקומית:

```bash
python3 -m http.server 8000
# http://localhost:8000
```

פריסה: GitHub Pages מתוך ענף `main`, תיקיית השורש.
